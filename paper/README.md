# Paper

`acl_paper.pdf` is the camera-ready paper; `acl_paper.tex` and `custom.bib` are its sources.

Compile with **LuaLaTeX** (the paper contains Thai script, which needs `fontspec` and `babel`
font switching; pdfLaTeX cannot render it). The Thai font is bundled in `fonts/` and loaded by
path, so no system font install is needed.

```
latexmk -lualatex acl_paper.tex
# or: lualatex acl_paper && bibtex acl_paper && lualatex acl_paper && lualatex acl_paper
```

On Overleaf, upload the folder and set Menu → Settings → Compiler → LuaLaTeX.

Figure 1 (`fig1-degradation.pdf`) is regenerated by `../viz/plot_degradation.py`.
